# IOC_analyser
A Python script that checks file hash values against a set of known IOCs hash values

# libraries
This imports certain libraries that provide ready-made tools used to carry out needed tasks

# IOCs
These are the hash values of the IOCs used in the script

# function
This Python method is used to calculate the hash value of a given file/s

# analysis & report
This section compares the returned values from the function against the #IOCs. 
It iterates through a directory called samples.
It also calculates the size of each file being compared, then displays the output of all analyses.
